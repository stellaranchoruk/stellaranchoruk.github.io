v2.1.6 MetaMask signing fix

This canvas contains the exact patch to apply to Stellar Cctp Bridge V2 1 5. It keeps pairing unchanged, but changes the Action required in MetaMask modal so signing opens the installed MetaMask app instead of the App Store.

Important split:
Initial WalletConnect pairing should still use https://metamask.app.link/wc?uri=.... Signing actions should not reuse that link and should not use the generic App Store-prone universal link. They should try metamask:// first.

Replace the v2.1.5 MetaMask signing helpers with this
